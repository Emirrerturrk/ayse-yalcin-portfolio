# Hedefler
"Bitti" ölçütünü kullanıcı koyar. Hedef, ölçütü karşılanınca ve ona bağlı açık görev kalmayınca kapanır.

- **G1:** Ayşe Yalçın için `Hero B (siyah beyaz ağ)` tasarımına sadık, yapay zeka klişelerinden uzak, Schibsted Grotesk + Hanken Grotesk tipografili, interaktif Canvas ağ animasyonlu Next.js ön yüzünün inşa edilmesi — bitti ölçütü: Next.js üzerinde çalışan, 360px-1440px arası kusursuz responsive, animasyonlu Hero B ve tüm portföy bölümlerini (Projeler, Hakkımda, Yetkinlikler, Deneyim, İletişim, i18n TR/EN) içeren canlı önizleme.
- **G2:** Veritabanı ve içerik yönetim katmanının (Supabase + Laravel Filament) kurulması — bitti ölçütü: Supabase PostgreSQL tablolarının tanımlanması, Laravel Filament üzerinden projelerin/içeriklerin yönetilebilmesi ve Next.js'in bu veriyi dinamik sunması.
- **G3:** GitHub deposuna push ve Vercel üzerinde canlı üretime alma — bitti ölçütü: Vercel üzerinde çalışan canlı domain/URL çıktısı, Lighthouse testlerinde (Performance ≥ 90, Accessibility ≥ 95, SEO ≥ 95) doğrulanmış sonuç.
